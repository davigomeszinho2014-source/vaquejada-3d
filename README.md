# Vaquejada 3D — Fazenda Brasileira

Projeto web 3D para publicar no GitHub Pages.

## Estrutura

- `index.html` — página principal.
- `jogo/jogo.html` — jogo 3D.
- `jogo/modelos/cavalos/` — coloque aqui modelos 3D de cavalos futuramente.
- `jogo/modelos/bois/` — coloque aqui modelos 3D de bois futuramente.
- `jogo/texturas/` — texturas do terreno, animais e construções.
- `jogo/sons/` — sons do ambiente, cavalos, bois e efeitos.
- `jogo/imagens/` — imagens e ícones.

## Publicar no GitHub Pages

1. Crie ou abra um repositório no GitHub.
2. Envie **todos os arquivos e pastas deste projeto**.
3. Nas configurações do repositório, abra **Pages**.
4. Escolha `Deploy from a branch`.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde o GitHub Pages publicar.
7. Abra o endereço do seu GitHub Pages.

## Controles

Celular:
- Joystick esquerdo: direção/movimento.
- ANDAR: velocidade baixa.
- TROTAR: velocidade média.
- GALOPAR: velocidade alta.
- PARAR: freio/parada.

Computador:
- W/S: frente/trás.
- A/D: virar.

## Próximas melhorias

A base já permite explorar a fazenda e a pista. Para um visual realmente realista, substitua os modelos simples por modelos 3D com esqueleto/animações e adicione texturas PBR, sons, partículas de poeira, água e chuva.
